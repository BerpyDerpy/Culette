# Culette · Custom Technology for Hard Problems

A showcase site built for GitHub Pages.

## Structure

- **`index.html`** — Main entry point (Culette portfolio)
- **`assets/`** — Images, 3D models, vendor libraries
- **`brand/`** — Culette brand assets (logos, SVGs)
- **`docs/`** — Design documentation and direction
- **`hero/`** — Alternative project pages
- **`archive/`** — Previous versions and experimental work

## GitHub Pages Setup

This site is configured to serve from the root of the repository.

### Deploy
Just push to the `main` branch. GitHub Pages will automatically serve `index.html` as the homepage.

### Configuration
- `.nojekyll` — Disables Jekyll processing (optional but recommended)
- All paths are relative from the root

## Hosting

Visit the live site at: `https://[username].github.io/Showcase`

## Local Development

Open `index.html` in a browser to preview. The site uses no build step—it's pure HTML/CSS/JS.
